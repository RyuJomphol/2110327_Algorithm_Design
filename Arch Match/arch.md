# Arch Match

## 1. วิเคราะห์โจทย์ Arch Match
มีแถวหนึ่งมิติที่มีช่องจำนวน `n` ช่อง แต่ละช่องมีค่าจำนวนเต็มบวก `A[i]`
เราสามารถจับคู่ช่องสองช่อง (i, j) โดยลากเส้นโค้งจากขอบบนกลางของช่องทั้งสอง เส้นโค้งต้องไม่ลงต่ำกว่าขอบบนและเส้นที่ลากห้ามตัดกัน
แต่ละช่องจับคู่ได้มากสุดหนึ่งครั้ง คะแนนของคู่ (i, j) คือ `A[i] * A[j]` เป้าหมายคือเลือกชุดคู่ที่ไม่ตัดกัน ให้ผลรวมคะแนนสูงสุด

ลักษณะสำคัญ:
- การจับคู่นี้คือการวางคู่ออร์เดอร์แบบไม่ตัดกัน (non-crossing matching) บนเซกเมนต์ของจุดเรียงตามลำดับ
- หากไม่มีการจับคู่เลย ผลลัพธ์เป็น 0

---

## 2. วิเคราะห์ที่มาสมการ Recurrence Relation
นิยาม `dp[l][r]` เป็นคะแนนสูงสุดที่สามารถได้จากช่วงช่อง `l..r` (รวมทั้งสองฝั่ง)
- กรณีฐาน: ถ้า `l >= r` ไม่มีคู่ได้ `dp[l][r] = 0` 

เมื่อพิจารณาช่วง `l..r` เรามีทางเลือกหลักสองแบบ:
1. ไม่จับคู่องค์ประกอบตัวสุดท้าย `r`: `dp[l][r] = dp[l][r-1]`
2. จับคู่ `r` กับตำแหน่ง `k` ใด ๆ ที่อยู่ใน `[l, r-1]` แล้วผลรวมจะเป็น:
   - คะแนนจากการจับคู่ `k` กับ `r`: `A[k] * A[r]`
   - บวกคะแนนจากช่วงซ้าย `l..k-1`: `dp[l][k-1]`
   - บวกคะแนนจากช่วงระหว่าง `k+1..r-1`: `dp[k+1][r-1]`

รวมเป็นสมการ:
$$
dp[l][r] = \max\left( dp[l][r-1],\; \max_{k=l}^{r-1}\{\; dp[l][k-1] + A[k]\cdot A[r] + dp[k+1][r-1]\}\right)
$$

หลักการ: การจับคู่ `k` กับ `r` แยกปัญหาออกเป็นสองช่วงที่ไม่ทับซ้อนกัน (ซ้ายและกลาง) ทำให้ปัญหาแก้ได้ด้วย DP แบบแบ่งช่วง

## 3. อธิบายโค้ด + ยกตัวอย่าง testcase
โค้ดทั่วไปจะใช้ตาราง DP สองมิติ `dp[1..n][1..n]` และเติมค่าจากช่วงสั้นไปยาว
ขั้นตอนสั้น ๆ:
1. อ่าน `n` และอาเรย์ `A[1..n]`
2. สร้าง `dp` ขนาด `(n+2)×(n+2)` กำหนดค่าเริ่มต้นเป็น 0
3. วนความยาวช่วง `len` จาก 2 ถึง `n`:
   - สำหรับ `l = 1..n-len+1` ให้ `r = l+len-1`
   - ตั้ง `dp[l][r] = dp[l][r-1]`
   - สำหรับทุก `k` ใน `l..r-1` คำนวณ `cand = dp[l][k-1] + A[k]*A[r] + dp[k+1][r-1]` และอัพเดต `dp[l][r] = max(dp[l][r], cand)`
4. คำตอบคือ `dp[1][n]`

Pseudocode:
```
for i in 1..n: dp[i][i] = 0
for len from 2 to n:
  for l from 1 to n-len+1:
    r = l + len - 1
    dp[l][r] = dp[l][r-1]
    for k from l to r-1:
      cand = dp[l][k-1] + A[k]*A[r] + dp[k+1][r-1]
      dp[l][r] = max(dp[l][r], cand)
answer = dp[1][n]
```

ตัวอย่าง (โจทย์):
```
10
2 4 7 8 2 3 4 5 1 9
```
ผลลัพธ์: **126**
(สามารถตรวจสอบด้วยการ run โค้ด; DP จะหาคู่ที่ให้ผลคูณรวมสูงสุดโดยไม่ตัดกัน)

หมายเหตุ: อัลกอริทึมจะได้ผลถูกต้องเพราะทุกการจับคู่ที่ไม่ตัดกันสามารถระบุให้คู่หนึ่งสุดท้ายเป็นตำแหน่ง `r` หรือไม่จับคู๋จบได้ ทำให้ recurrence ครอบคลุมทุกกรณี

---

## 4. Time Complexity
- การคำนวณ `dp[l][r]` สำหรับแต่ละช่วงใช้การค้นหา `k` ในช่วงซึ่งทำให้ค่าใช้จ่าย `O(len)`
- มีช่วงทั้งหมดประมาณ `O(n^2)` ดังนั้นเวลาโดยรวมเป็น **O(n^3)**
- พื้นที่ใช้ `O(n^2)` สำหรับตาราง `dp`

สามารถปรับปรุงได้ในบางกรณีด้วยเทคนิคพิเศษหรือโครงสร้างข้อมูลเพิ่มเติม แต่ทั่วไปวิธีนี้ตรงและเข้าใจง่ายสำหรับการสอน

---

สรุป: ปัญหา Arch Match เป็นปัญหา DP แบบคั่นช่วง (interval DP) ที่คล้ายกับการจับคู่ไม่ตัดกันใน RNA secondary structure หรือปัญหาเมทริกซ์พาร์ซิ่ง โดย recurrence จะพิจารณาว่าตำแหน่งสุดท้ายจะจับคู่กับตำแหน่งใดหรือไม่จับคู่เลย
