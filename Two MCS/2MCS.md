# Two MCS - วิเคราะห์และคำอธิบาย

## 1. วิเคราะห์โจทย์

ให้มีอาเรย์เต็มจำนวน `A` ขนาด `n` เราต้องเลือกช่วงติดกันไม่เกินสองช่วง (non-overlapping) เพื่อให้ผลรวมของสมาชิกของช่วงที่เลือกมีค่ามากที่สุด

- ทุกช่วงต้องมีความยาวอย่างน้อย 1
- สามารถเลือกเพียงช่วงเดียวได้
- สองช่วงต้องไม่มีสมาชิกตัวใดซ้อนทับกัน

ตัวอย่างอินพุตที่ใช้ในการสาธิต:
```
10
-1 3 -1 2 -4 -5 7 -3 8 -4
```
คำตอบที่คาดไว้: `16`
(ตัวเลือกที่ดีคือช่วง `[2..4] = 3 + (-1) + 2 = 4` และช่วง `[7..9] = 7 + (-3) + 8 = 12` → รวม = 16)

## 2. Recurrence Relation (แนวทาง DP / Kadane-based)

แนวคิดหลัก: แยกปัญหาเป็นสองฝั่ง

- คำนวณ `L[i]` = ผลรวมสูงสุดของช่วงติดกันใด ๆ ที่อยู่ภายในตำแหน่ง `0..i` (ช่วงที่จบ ≤ i)
- คำนวณ `R[i]` = ผลรวมสูงสุดของช่วงติดกันใด ๆ ที่อยู่ภายในตำแหน่ง `i..n-1` (ช่วงที่เริ่ม ≥ i)

การคำนวณ `L` ใช้ Kadane แบบสะสม:
- `end_here[i] = max(A[i], end_here[i-1] + A[i])`  (ผลรวมสูงสุดของช่วงที่ลงท้ายที่ i)
- `L[i] = max(L[i-1], end_here[i])`

สำหรับทิศทางขวา (คำนวณ `R`) ทำแบบเดียวกันแต่เดินจากขวาไปซ้าย:
- `start_here[i] = max(A[i], start_here[i+1] + A[i])`  (ผลรวมสูงสุดของช่วงที่เริ่มที่ i)
- `R[i] = max(R[i+1], start_here[i])`

เมื่อได้ `L` และ `R` แล้ว คำตอบสำหรับการเลือกไม่เกินสองช่วงที่ไม่ทับกันคือ:
- สำหรับทุกตำแหน่งแบ่ง `i` (0 ≤ i < n-1): พิจารณาเลือกช่วงหนึ่งที่อยู่ซ้ายของแบ่ง (≤ i) และอีกช่วงที่อยู่ขวาของแบ่ง (≥ i+1)
  - ค่าสุทธิ = `L[i] + R[i+1]`
- นอกจากนี้ยังต้องพิจารณากรณีเลือกเพียงช่วงเดียว: `L[n-1]`

สุดท้าย:
```
answer = max( max_{i=0..n-2} (L[i] + R[i+1]), L[n-1] )
```

เหตุผล: การแบ่งตำแหน่ง i แยกช่วงซ้าย/ขวาให้แน่ใจว่าไม่มีการทับซ้อน (ช่วงซ้ายจบ ≤ i และช่วงขวาเริ่ม ≥ i+1)

## 3. อธิบายโค้ด (`two_mcs.cpp`) + ตัวอย่าง testcase

โค้ดหลัก (ย่อ):
- อ่าน `n` และอาเรย์ `A`
- ถ้า `n == 0` ให้ออก
- สร้างอาเรย์ `L[n]` โดยใช้ Kadane ทางซ้าย:
  - เก็บ `running_sum` เป็น end_here และ `best_so_far` เป็น L
- สร้างอาเรย์ `R[n]` โดยใช้ Kadane ทางขวา (เดินจากขวาไปซ้าย)
- คำนวณคำตอบด้วยการวน `i` ตั้งแต่ `0` ถึง `n-2` เพื่อหา `max(L[i] + R[i+1])`
- เปรียบเทียบกับ `L[n-1]` เผื่อกรณีเลือกช่วงเดียว
- แสดงผลลัพธ์

ตัวแปรสำคัญในโค้ดที่ให้มา:
- `L[i]` เก็บผลลัพธ์ MCS สำหรับ prefix ending ≤ i
- `R[i]` เก็บผลลัพธ์ MCS สำหรับ suffix starting ≥ i
- `running_sum` เก็บผลรวมของ subarray ที่กำลังพิจารณา (Kadane's end_here)
- `best_so_far` เก็บผลลัพธ์สูงสุดที่พบจนถึงปัจจุบัน

ตัวอย่าง (จากโจทย์):
```
n = 10
A = [-1, 3, -1, 2, -4, -5, 7, -3, 8, -4]
```
การคำนวณสรุป (คร่าว ๆ):
- `L` ประมาณ: [-1, 3, 3, 4, 4, 4, 7, 7, 12, 12]
- `R` ประมาณ: [12, 12, 12, 12, 12, 12, 12, 12, 8, -4]
(ค่าที่สำคัญคือ `L[3] = 4` (ช่วง `1..3` หรือ `1..3` ใน 1-indexed คือ [2..4]) และ `R[6] = 12` (ช่วง `6..8`) → `4 + 12 = 16`)

สุดท้ายโปรแกรมจะพิมพ์ `16` ซึ่งตรงกับคำตอบที่คาดไว้

## 4. Time & Space Complexity

- การคำนวณ `L` ด้วย Kadane: O(n)
- การคำนวณ `R` ด้วย Kadane (ขวา→ซ้าย): O(n)
- การค้นหา max over split positions: O(n)

รวมเวลา: O(n)

พื้นที่:
- เก็บ `L` และ `R` ขนาด `n` → O(n)
- ถ้าต้องการลดหน่วยความจำ สามารถคำนวณ `L` แล้ววนจากขวาไปซ้ายเก็บค่า `R` ชั่วคราว และอัพเดตคำตอบโดยไม่เก็บทั้ง `R` และ `L` พร้อมกัน ซึ่งลดพื้นที่เป็น O(n) → O(n) (หรือ O(1) เพิ่มเติมด้วยเทคนิคลดหน่วยความจำขั้นสูง)

สรุป:
- Time: O(n)
- Space: O(n)
