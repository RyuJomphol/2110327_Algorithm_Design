# Bigger Billboard

## 1. วิเคราะห์โจทย์ Bigger Billboard

the problem is similar to the "Billboard (Advertising Placement)" exercise.

คุณมีไดรเวย์ยาวมีป้ายโฆษณาเรียง 1..N แต่ละตำแหน่งมีค่า `c[i]` เป็นจำนวนลูกค้าที่เห็น
คุณต้องการเช่าป้ายให้ได้ผลรวมลูกค้ามากที่สุด แต่มีเงื่อนไข:

- หากเช่าป้ายที่ตำแหน่ง `i` จะ **ห้าม** เช่าป้ายที่ `i-2`, `i-1`, `i+1`, `i+2`
- นั่นคือป้ายใด ๆ ภายในระยะ 2 ของ `i` ถูกปฏิเสธ
- เป้าหมาย: เลือกชุดตำแหน่งที่ไม่ขัดกับกฎ เพื่อให้ผลรวม `Σ c[i]` มากที่สุด

โจทย์นี้เป็นเวอร์ชัน "เว้นระยะ 2" ของการเลือกป้าย เดียวกับปัญหา
Maximum Weight Independent Set บนเส้นตรงที่ขนาดระยะเว้นเท่ากับ 2

## 2. วิเคราะห์ที่มาสมการ Recurrence Relation

define `dp[i]` = ค่าสูงสุดเมื่อพิจารณาป้าย `1` ถึง `i` (เลือกจาก prefix)

เพื่ออัพเดตเมื่อถึง `i` มีสองทางเลือกหลัก:
1. **ไม่เลือก** ป้าย `i`: ผลลัพธ์คือ `dp[i-1]`
2. **เลือก** ป้าย `i`: เนื่องจากห้ามใช้ `i-2` และ `i-1` และ `i+1`/`i+2` เพียงดูด้านซ้าย
   - คุณต้องข้ามจุดก่อนหน้า 2 ตำแหน่งด้วยจึงสามารถเชื่อมกับ `dp[i-3]` หรือ `dp[i-4]` ขึ้นกับการจัดการ
   - แต่กฎจากโจทย์กล่าวว่าเช่าป้าย `i` ห้ามเช่า `i-1` หรือ `i-2` ดังนั้น
     คุณสามารถรวมกับ `dp[i-3]` ได้โดยตรง

Recurrence จึงเป็น:
```
dp[i] = max(dp[i-1], dp[i-3] + c[i])
```
โดยกำหนด `dp[0] = 0`, `dp[-1]=dp[-2]=0` เพื่อจัดการขอบเขต

หากต้องการเก็บข้อมูลเพิ่มเติม (เช่นติดตามเลือกป้ายก่อนหน้า) ก็ทำได้ แต่ไม่จำเป็น

## 3. อธิบายโค้ด + ยกตัวอย่าง testcase
โค้ดใน `bigger_billboard.cpp` (หรือไฟล์อื่น ๆ) อ่าน `N` แล้วค่าพื้นฐาน
สร้างอาเรย์ `c[1..N]` และ `dp[0..N]`  

### ขั้นตอนสำคัญ
1. อ่าน `N` และ `c` values
2. กำหนด `dp[0]=0`, `dp[1]=c[1]`, `dp[2]=max(c[1],c[2])` (ดูเงื่อนไข)  
3. วน `i=3..N` ใช้สูตร
   ```
   dp[i] = max(dp[i-1], dp[i-3] + c[i]);
   ```
4. ผลลัพธ์คือ `dp[N]`

### ตัวอย่าง
```
10
48 1 3 95 2 1 3 44 22 2
```
- ผ่านค่าสูงสุดได้ `187`

> output: **187**

---

## 4. Time Complexity
- วนลูปเดียวถึง `N` ทำงาน O(1) ต่อขั้นตอน

**เวลา**: `O(N)`  
**พื้นที่**: `O(N)` (สามารถลดเป็น `O(1)` หากเก็บเฉพาะสามค่าล่าสุด)

### สรุป
Bigger Billboard เป็นปัญหา DP แบบเลือกป้ายโดยเว้นระยะ 2 ตำแหน่ง
ใช้ recurrence เรียบง่ายและเวลาเชิงเส้น เหมาะสมสำหรับอ่านการสอน
