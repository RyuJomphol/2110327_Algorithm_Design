# ปัญหา Tiling (L-shaped Tiling)

## 1. วิเคราะห์โจทย์

* ปัญหา: ปูพื้นขนาด $L \times L$ (โดย $L=2^k$) ซึ่งมี รู (Hole) อยู่ 1 จุด ให้เต็มด้วยกระเบื้องรูปตัว L (Trominoes)

### ตัวอย่างโจทย์
- **Input**: L=4, hole_x=1, hole_y=2
  - กระดาน: 4 × 4
  - รูอยู่ที่ตำแหน่ง (1, 2)
- **Output**: จำนวนกระเบื้องที่ใช้ = 5 ชิ้น และตำแหน่งของแต่ละชิ้น

### วิธีการแก้ไข: Divide and Conquer

**ความเข้าใจคร่าว:**
1. แบ่งตารางใหญ่เป็น 4 ส่วนย่อย (Quadrants) เท่าๆ กัน
2. รูจริงจะอยู่ในส่วนย่อยใดส่วนย่อยหนึ่งเพียงส่วนเดียว
3. **กลยุทธ์สำคัญ:** เราจะวางกระเบื้อง 1 ชิ้นตรง **จุดกึ่งกลาง (Center)** เพื่อปิดมุมของอีก 3 ส่วนย่อยที่ ไม่มีรู
4. การทำแบบนี้จะสร้าง **"รูเทียม" (Virtual Holes)** ขึ้นมาใน 3 ส่วนนั้น ทำให้ตอนนี้ทั้ง 4 ส่วนย่อยมี "รู" (จริง 1, เทียม 3) อยู่ในพื้นที่ของตัวเองครบทุกส่วน
5. ทำแบบนี้แบบ recursive จนกว่าเป็น 2×2

## 2. วิเคราะห์โค้ด

```cpp
struct Command {
    int type;      // ประเภทกระเบื้อง (0, 1, 2, 3)
    int x, y;      // ตำแหน่งมุมบนซ้ายของกระเบื้อง
};

vector<Command> ans;  // เก็บรายการกระเบื้องทั้งหมด

void place_block(int size, int x, int y, int hole_x, int hole_y) {
```

### ตัวแปรสำคัญ:
- `size`: ขนาดของกระดาน (2^L)
- `x, y`: มุมบนซ้ายของกระดาน
- `hole_x, hole_y`: ตำแหน่งของรู
- `center_x, center_y`: ตำแหน่งกึ่งกลาง

### ตรรกะการทำงาน:

**1. Base Case** (size == 1)
```cpp
if (size == 1) return;
```
- ถ้ากระดาน 1×1 แสดงว่าเป็นรู ให้ออก

**2. Divide:**
```cpp
int mid = size / 2;
int center_x = x + mid;
int center_y = y + mid;
int top_left_x = center_x - 1;
int top_left_y = center_y - 1;
```
- แบ่งกระดานเป็น 4 ส่วน
- ค้นหามุมบนซ้ายของจุดศูนย์กลาง

**3. Conquer:**
- ตรวจสอบว่ารูอยู่ควอดแรนต์ไหน (4 กรณี)
- แล้วใส่กระเบื้อง L-shaped ที่มุมกึ่งกลางของอีก 3 ควอดแรนต์
- เรียก recursive ทั้ง 4 ส่วน

### ตัวอย่างการทำงาน (size=4, hole=(1,2)):

```
กรณีที่ 2: hole อยู่ Top-Right (hole_x >= center_x, hole_y < center_y)
↓
ans.push_back({1, top_left_x, top_left_y});
```
- Type 1 = ประเภทกระเบื้องที่ 2 (ต่างจากประเภทอื่น)
- วาง L-shaped ที่มุม (top_left_x, top_left_y)

## 3. ตัวอย่าง Test Case

### Input:
```
4 1 2
```

### Output:
```
5
3 1 1
3 0 0
2 2 0
1 0 2
3 2 2
```

### ความหมาย:
- จำนวนกระเบื้อง: 5 ชิ้น
- ชิ้นที่ 1: Type 3 ที่ตำแหน่ง (1, 1)
- ชิ้นที่ 2: Type 3 ที่ตำแหน่ง (0, 0)
- ชิ้นที่ 3: Type 2 ที่ตำแหน่ง (2, 0)
- ชิ้นที่ 4: Type 1 ที่ตำแหน่ง (0, 2)
- ชิ้นที่ 5: Type 3 ที่ตำแหน่ง (2, 2)

### ขั้นตอนการแก้ (ระดับ 1: size=4):

```
เราจะเริ่มเรียกฟังก์ชัน: `place_block(4, 0, 0, 1, 2)`

**Step 1: แบ่งตาราง 4x4**
* **Center:** จุดตัดอยู่ที่ $(2, 2)$
* **เช็คตำแหน่งรู:** รูอยู่ที่ $(1, 2)$
  * เทียบกับ Center $(2, 2)$: $X < 2$ (ซ้าย), $Y \ge 2$ (ล่าง)
  * รูอยู่ใน **Quadrant ซ้ายล่าง (Bottom-Left)**
* **การกระทำ:** ต้องวางกระเบื้องปิดมุมของ 3 ด้านที่เหลือ (บนซ้าย, บนขวา, ล่างขวา)
  * ต้องใช้กระเบื้อง **Type 2** (รูปตัว $\Gamma$ หัวกลับ) เพื่อเว้นที่ว่างให้มุมซ้ายล่าง
  * คำสั่ง: `2 1 1` (Type 2 ที่พิกัด 1,1)
  * *หมายเหตุ: พิกัด 1,1* คือมุมบนซ้ายของ Block 2x2 ที่วางลงไป
  
  **สถานะตารางหลัง Step 1:** (H = รูจริง, V = รูเทียมที่เกิดจากกระเบื้องตรงกลาง, # = กระเบื้องตรงกลาง)

  0   1   2   3
    +---+---+---+---+
  0 |   |   |   |   |  <- Top-Left (ยังว่าง)
    +---+---+---+---+
  1 |   | # | # |   |  <- Top-Right (ยังว่าง)
    +---+---+---+---+
  2 |   | H | # |   |  <- Bottom-Left (มีรูจริง)
    +---+---+---+---+
  3 |   |   |   |   |  <- Bottom-Right (ยังว่าง)
    +---+---+---+---+
          ^
     วาง Tile Type 2 ตรงกลาง
     (ครอบคลุม 1,1 | 2,1 | 2,2)
     (สร้างรูเทียมให้ TL, TR, BR)

จากนั้นโค้ดจะเรียก Recursion 4 ครั้ง:

---

**Step 2: Recurse Top-Left (TL)**

* เรียก: `place_block(2, 0, 0, 1, 1)`
  * ขนาด 2, มุม (0,0), รู(เทียม)อยู่ที่ (1,1)
* **วิเคราะห์:** รูอยู่ที่ (1,1) คือมุมล่างขวาของกล่องนี้ -> ต้องวาง Tile **Type 3** (เว้นล่างขวา) ที่ (0,0)
คำสั่ง: `3 0 0`

**Step 3: Recurse Top-Right (TR)**
* เรียก: `place_block(2, 2, 0, 2, 1)`
  * ขนาด 2, มุม (2,0), รู(เทียม)อยู่ที่ (2,1)
* **วิเคราะห์:** รูอยู่ที่ (2,1) คือมุมล่างซ้ายของกล่องนี้ -> ต้องวาง Tile **Type 2** (เว้นล่างซ้าย) ที่ (2,0)
* คำสั่ง: `2 2 0`

**Step 4: Recurse Bottom-Left (BL) [มีรูจริง]**
เรียก: `place_block(2, 0, 2, 1, 2)`
  * ขนาด 2, มุม (0,2), รู(จริง)อยู่ที่ (1,2)
* **วิเคราะห์:** รูอยู่ที่ (1,2) คือมุมบนขวาของกล่องนี้ -> ต้องวาง Tile **Type 1** (เว้นบนขวา) ที่ (0,2)
* คำสั่ง: `1 0 2`

Step 5: Recurse Bottom-Right (BR)
* เรียก: `place_block(2, 2, 2, 2, 2)`
  * ขนาด 2, มุม (2,2), รู(เทียม)อยู่ที่ (2,2)
* **วิเคราะห์:** รูอยู่ที่ (2,2) คือมุมบนซ้ายของกล่องนี้ -> ต้องวาง Tile **Type 0** (เว้นบนซ้าย) ที่ (2,2)
คำสั่ง: `0 2 2`

## 4. ความซับซ้อน (Complexity Analysis)

### Big O (Upper Bound):

**ทำไมถึงต้อง 5 ชิ้น?**

กระดาน 2^L × 2^L มีเซลล์ทั้งหมด = $(2^L)^2 = 2^{2L} = 4^L$ เซลล์

แต่ละ L-shaped tile ครอบ 3 เซลล์

จำนวน tiles ที่ต้องใช้ = $\frac{4^L - 1}{3}$

สำหรับ L=4: $\frac{4^4 - 1}{3} = \frac{256 - 1}{3} = \frac{255}{3} = 85$ ชิ้น

แต่ output เท่ากับ 5 ชิ้น เพราะ code ชั้น current เป็น recursive level 1 เพียง

**Time Complexity:**

$$T(n) = 4 \cdot T(n/2) + O(1)$$

โดยที่:
- เรียก recursive 4 ครั้ง กับ size ลดลงครึ่งหนึ่ง
- การ check และ place block ใช้ $O(1)$

ใช้ Master Theorem:
- $a = 4$
- $b = 2$
- $f(n) = O(1)$
- $n^{\log_b a} = n^{\log_2 4} = n^2$

เนื่องจาก $f(n) = O(1) = O(n^{2-\epsilon})$ (ที่ $\epsilon=2$)

$$T(n) = \Theta(n^2) = \Theta(4^L)$$

**Space Complexity:**

- Recursion depth = $O(L)$ (เรื่ย recursive L ครั้งเพราะ size หารด้วย 2)
- Vectors คงที่ = $O(4^L)$ (เก็บ tiles ทั้งหมด)
- Total = $O(4^L)$

### Big Theta (Exact Bound):

$$\Theta(\text{Time}) = \Theta(4^L)$$
$$\Theta(\text{Space}) = \Theta(4^L)$$

### เหตุผล:
- Algorithm ต้องสร้าง $\frac{4^L - 1}{3} \approx \Theta(4^L)$ tiles
- ต้องตรวจสอบแต่ละ recursion call $\Theta(4^L)$ ครั้ง
- เนื่องจาก recursive tree มี depth $L$ และแต่ละระดับมี 4 branches ที่สูง
- ทั้ง time และ space จึง dominated โดย $\Theta(4^L)$
