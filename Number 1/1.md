## 1. วิเคราะห์โจทย์
โจทย์: ให้จำนวนเต็มบวก `n` และช่วงตำแหน่ง `[l, r]` (1-indexed) ให้สร้างลำดับตามกฎ

S(n) = S(floor(n/2)) + (n % 2) + S(floor(n/2))

โดยฐานคือ S(0) = "" (ว่าง) และ S(1) = "1" (หรือในโค้ดเมื่อ n==1 คืน 1) — ต้องนับจำนวนตัวอักษร '1' ในตำแหน่งตั้งแต่ `l` ถึง `r` ใน S(n)

วิธีที่ใช้: จำแนกตำแหน่งแบบ recursive โดยไม่ต้องสร้างสตริงทั้งหมด
- คำนวณความยาวของ S(n) (ฟังก์ชัน `get_length`) โดยลด n /= 2 ทีละขั้นและใช้สูตร len = len*2 + 1
- ใช้ฟังก์ชัน `count_ones(n, start, end, left, right)` ที่รักษาช่วง index ของ S(n) เป็น `[start..end]` แล้ว
  - ถ้าช่วงไม่ทับกับ `[left,right]` ให้ตัด
  - ถ้า n==0 return 0; ถ้า n==1 return 1 (เพราะ S(1) = "1")
  - คำนวณตำแหน่งกลาง `mid` และแบ่งเป็นซ้าย-กลาง-ขวา: เรียก recursion บนซ้าย และขวา และถ้าตำแหน่งกลางอยู่ในช่วง ให้เพิ่ม `n%2`

เทคนิคคือการทำ prune (ตัดสาขา) เมื่อช่วงไม่ทับกับคำถาม ดังนั้นไม่ต้องเก็บสตริงยาวๆ

## 2. วิเคราะห์โค้ด
- `get_length(int n)`
  - คืนความยาวของ S(n) โดยเริ่ม len=1 (สำหรับ n>=1) แล้วทำ `n /= 2` ซ้ำ ๆ พร้อม `len = len * 2 + 1` จน n<=1
  - ผลสุดท้ายเท่ากับ `2^{k+1}-1` โดย k = floor(log2 n)

- `count_ones(int n, int start, int end, int left, int right)`
  - ถ้าช่วง `[start,end]` ไม่ทับ `[left,right]` หรือ n==0 → return 0
  - ถ้า n==1 → return 1
  - คำนวณ `mid` = (start+end)/2
  - `res += count_ones(n/2, start, mid-1, left, right)`  // ซ้าย
  - ถ้า mid ใน [left,right] → `res += n%2`                 // กลาง
  - `res += count_ones(n/2, mid+1, end, left, right)`   // ขวา

- `main()`
  - อ่าน `n, l, r`
  - ถ้า n==0 พิมพ์ 0
  - คำนวณ `total_length = get_length(n)`
  - เรียก `count_ones(n, 1, total_length, l, r)` และพิมพ์ผล

Input:
```

```
Output:
```
5
```

เหตุผล (construct S(10) โดยนิยาม):
- เริ่มจาก S(1) = 1
- S(2) = S(1) + 0 + S(1) = 1 0 1
- S(5) = S(2) + 1 + S(2) = 1 0 1 1 1 0 1  (len=7)
- S(10) = S(5) + 0 + S(5) =

Positions 1..15 (S(10)):

## 4. Big O / Big Theta
- Let k = floor(log2 n). Then total_length = 2^{k+1}-1 = Θ(2^{k}) and since 2^{k} ≤ n < 2^{k+1} we have total_length = Θ(n).
- `count_ones` ในกรณีแย่สุดอาจต้องเยี่ยมชมทุกตำแหน่ง → Time = Θ(total_length) = Θ(n).
- Recursion depth = O(k) = O(log n) → Space (stack) = Θ(log n).

สรุป:
- Time = Θ(n) (worst-case)
- Space = Θ(log n) (call stack) + O(1) extra
