# 0-1 Knapsack

## 1. วิเคราะห์โจทย์ Knapsack
โจทย์ 0-1 Knapsack: มีของ `n` ชิ้น แต่ละชิ้น `i` มีน้ำหนัก `w[i]` และมูลค่า `v[i]` ต้องเลือกชุดของชิ้น (แต่ละชิ้นเลือกได้ 0 หรือ 1) ให้ผลรวมน้ำหนักไม่เกินความจุ `M` และผลรวมมูลค่ามากที่สุด

ผลลัพธ์ที่ต้องการอาจเป็นค่ามูลค่าสูงสุด หรือรายการชิ้นที่เลือกได้ (reconstruction)

---

## 2. วิเคราะห์ที่มาสมการ Recurrence Relation
นิยามฟังก์ชัน DP

- `V(a,b)` = มูลค่าสูงสุดที่ได้โดยพิจารณาของชิ้น `1..a` และความจุ `b` (0 ≤ a ≤ n, 0 ≤ b ≤ M)

ฐาน:
```
V(0, b) = 0  for all b
V(a, 0) = 0  for all a
```

ถ้าพิจารณาชิ้น `a`:
- ถ้าไม่เลือกชิ้น `a`: ค่าเป็น `V(a-1, b)`
- ถ้าเลือกได้ (b ≥ w[a]): ค่าเป็น `V(a-1, b - w[a]) + v[a]`

ดังนั้น recurrence:
```
V(a,b) = V(a-1,b)                                  if b < w[a]
V(a,b) = max( V(a-1,b), V(a-1, b - w[a]) + v[a] )  if b ≥ w[a]
```

การคำนวณโดยปกติใช้ตาราง `dp[0..n][0..M]` เติมโดยเพิ่ม `a` จาก 1 → n และ `b` จาก 0 → M

---

## 3. อธิบายโค้ด + ยกตัวอย่าง testcase
โค้ดตัวอย่าง (แนวทาง):
```
// สร้างตาราง dp (n+1) x (M+1)
for a = 0..n: dp[a][0] = 0
for b = 0..M: dp[0][b] = 0
for a = 1..n:
  for b = 0..M:
    dp[a][b] = dp[a-1][b]
    if b >= w[a]:
      dp[a][b] = max(dp[a][b], dp[a-1][b-w[a]] + v[a])
// ค่ามากสุด = dp[n][M]

// หากต้องการรายการชิ้นที่เลือก (reconstruction):
let cur = M
for a = n down to 1:
  if dp[a][cur] != dp[a-1][cur]:
    select item a
    cur -= w[a]
```

### ตัวอย่าง (จากหัวข้อ)
อินพุต (ตีความ):
- `n = 5`, `M = 5`
- มูลค่า `v = [3, 10, 6, 3, 5]`  (ชิ้น 1..5)
- น้ำหนัก `w = [5, 5, 3, 1, 1]`

คำนวณด้วย DP จะพบว่า การเลือกชิ้น `3, 4, 5` (น้ำหนัก 3+1+1 = 5) ให้มูลค่า `6 + 3 + 5 = 14` ซึ่งเป็นค่ามากสุด (มากกว่าเลือกชิ้น 2 เดี่ยวๆ ที่ให้ 10)

ผลลัพธ์ตัวอย่าง (reconstruction):
```
จำนวนชิ้นที่เลือก: 3
รายการชิ้น (index): 5 4 3
```
(รูปแบบการพิมพ์ขึ้นกับโค้ด — บางโค้ดพิมพ์รายการจากใหญ่→เล็ก)

หมายเหตุ: ไฟล์ `knapsack_items.cpp` ใน repository ใช้วิธีการย้อนกลับจากตาราง `dp` ที่เตรียมไว้แล้ว (อ่าน `dp` จากอินพุต) เพื่อหาชิ้นที่เลือก — แนวคิด reconstruction เหมือนกัน

---

## 4. Time & Space Complexity
- การคำนวณ dp แบบเต็มใช้เวลา `O(n * M)` (ลูปสองชั้น a × b)
- พื้นที่ใช้ `O(n * M)` สำหรับตาราง `dp`

หากต้องการลดพื้นที่ สามารถใช้ `O(M)` ด้วย rolling array (เก็บเฉพาะแถว `a-1` และ `a`) แต่การทำ reconstruction จะต้องมีวิธีเก็บข้อมูลเพิ่มเติม (เช่นเก็บบิทหรือบันทึกการตัดสินใจ) หรือรัน DP ซ้ำเล็กน้อย

---

## สรุป
ปัญหา 0-1 Knapsack แก้ได้ด้วย DP แบบตารางที่ใช้ recurrence ข้างต้น และสามารถดึงรายการชิ้นที่เลือกได้โดยการย้อนกลับจากตาราง `dp` หลังการคำนวณ คำตอบตัวอย่างที่ให้คือเลือก 3 ชิ้น `5 4 3` ให้มูลค่าสูงสุด 14
