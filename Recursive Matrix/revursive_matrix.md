# Recursive Matrix

## 1. วิเคราะห์โจทย์ — วิธีที่ใช้
โจทย์นี้สร้างเมทริกซ์ขนาด `2^a × 2^a` โดยใช้กฎ recursive ที่กำหนดผ่านฟังก์ชัน `recur`:
- พารามิเตอร์หลัก: `a` (ระดับ/ความลึก), `b` (ค่าพื้นฐานที่ใส่ลงในบางตำแหน่ง)
- เมทริกซ์ถูกแบ่งทีละระดับเป็น 4 ควอแดรนต์ (top-left, top-right, bottom-left, bottom-right)
- แต่ละควอแดรนต์จะถูกเติมด้วยการเรียก `recur` อีกครั้งด้วย `a-1` และปรับค่า `b` ตามกฎ:
  - top-left: ใช้ค่า `b` เดิม
  - top-right: ใช้ค่า `b-1`
  - bottom-left: ใช้ค่า `b+1`
  - bottom-right: ใช้ค่า `b` เดิม

แนวทาง: Divide-and-Conquer (recursion) ที่ลงจนถึงระดับฐาน `a == 0` แล้วเขียนค่า `b` ลงในตำแหน่งที่สอดคล้อง


## 2. วิเคราะห์โค้ด

ฟังก์ชันสำคัญ:

```cpp
void recur(vector<vector<int>> &v, int a, int b, int top, int bottom, int left, int right)
```
- `v`: เมทริกซ์ผลลัพธ์ (passed by reference)
- `a`: จำนวนระดับที่เหลือ (ถ้า `a==0` จะเป็นฐาน)
- `b`: ค่าที่จะเขียนเมื่อถึงฐาน (หรือส่งต่อไปยังซับคอลล์)
- `top, bottom, left, right`: ขอบเขต (index) ของบล็อกย่อยในเมทริกซ์ที่กำลังเติม (half-open interval: top..bottom-1, left..right-1)

ตรรกะภายใน:
1. ถ้า `a == 0` → กำหนด `v[top][left] = b` และ return (ฐาน: เขียน 1 ตำแหน่ง)
2. คำนวณ `mid_r = (top + bottom) / 2` และ `mid_c = (left + right) / 2` เพื่อแบ่งบล็อกเป็น 4 ช่วง
3. เรียก `recur` 4 ครั้งกับพารามิเตอร์และค่าของ `b` ดังนี้ (ตามลำดับ):
   - Top-left: `recur(v, a-1, b, top, mid_r, left, mid_c);`
   - Top-right: `recur(v, a-1, b-1, top, mid_r, mid_c, right);`
   - Bottom-left: `recur(v, a-1, b+1, mid_r, bottom, left, mid_c);`
   - Bottom-right: `recur(v, a-1, b, mid_r, bottom, mid_c, right);`

ผลคือเมื่อ `a` ลดลงเป็น 0 ทุก leaf จะเขียนค่า `b` ลงในเซลล์หนึ่งตำแหน่ง ทำให้เมทริกซ์เต็มในที่สุด


## 3. ตัวอย่าง Test Case (ตามที่ให้)
Input:
```
3 3
```
- `a = 3` → เมทริกซ์ขนาด `2^3 = 8` → ผลลัพธ์เป็นเมทริกซ์ `8×8`
- `b = 3` เป็นค่าพื้นฐานเริ่มต้น

Expected Output (รูปแบบเมทริกซ์ 8×8):
```
3 2 2 1 2 1 1 0 
4 3 3 2 3 2 2 1 
4 3 3 2 3 2 2 1 
5 4 4 3 4 3 3 2 
4 3 3 2 3 2 2 1 
5 4 4 3 4 3 3 2 
5 4 4 3 4 3 3 2 
6 5 5 4 5 4 4 3 
```

อธิบายการก่อรูปทีละระดับ (ASCII / ขั้นตอน):

- ระดับฐานสุด (a=0): แต่ละ leaf เป็น 1 เซลล์ที่เขียนค่า `b` ปัจจุบัน

- ถ้าพิจารณา sub-block ขนาด 2×2 (เมื่อ a=1) การเรียก 4 ครั้ง (top-left, top-right, bottom-left, bottom-right) จะสร้างรูปแบบ 2×2 ดังนี้ (ใช้ตัวอธิบาย `b` เป็นค่า `B` ณ จุดนั้น):

  ข้อมูลสำหรับ block ขนาด 2×2 ที่เกิดจาก `recur(..., a=1, b=B, ...)`:

  top-left  (a=0, b=B) → เขียน B ที่ (0,0)
  top-right (a=0, b=B-1) → เขียน B-1 ที่ (0,1)
  bottom-left (a=0, b=B+1) → เขียน B+1 ที่ (1,0)
  bottom-right (a=0, b=B) → เขียน B ที่ (1,1)

  ดังนั้น block 2×2 จะเป็น:

  [ B    B-1 ]
  [ B+1  B   ]

- ขยายขึ้นเป็น 4×4 (a=2): แต่ละบล็อก 4×4 ประกอบด้วยสี่บล็อก 2×2 ตามกฎการเปลี่ยน `b` ของการเรียกซ้อน (top-left ใช้ B, top-right ใช้ B-1, bottom-left ใช้ B+1, bottom-right ใช้ B)
  - ถ้าแทนค่า B = 3 ในระดับบน จะได้รูปแบบ 4×4 ที่แต่ละ 2×2 มีค่าแปรไปตามสูตรข้างต้น

- ขยายอีกระดับเป็น 8×8 (a=3): ทำซ้ำกฎเดิมอีกครั้ง ทำให้ได้เมทริกซ์สุดท้ายตามที่แสดงในตัวอย่าง

เพื่อให้เห็นภาพแบบย่อ (ตัวอย่างการวางค่าที่มุมของเมทริกซ์ 8×8):

Indices (0-based) มุมบนซ้ายเป็น (0,0)

มุมบนซ้าย 4×4 block (B เริ่มต้น = 3):

Top-left 4×4  (เริ่ม b=3)  -> จะมีค่าในบล็อกย่อย 2×2 (B, B-1, B+1, B)
Top-right 4×4 (เริ่ม b=2)  -> จะได้ค่าลดลง
Bottom-left 4×4 (เริ่ม b=4) -> ค่าจะเพิ่มขึ้น
Bottom-right 4×4 (เริ่ม b=3)

เมื่อประกอบทั้ง 4 block นี้จะได้เทเบิล 8×8 ตามที่แสดงข้างต้น

(ตัวอย่างเต็มแสดงไว้ในผลลัพธ์ที่คัดลอกมา)


## 4. Complexity (Big O / Big Theta)

- จำนวนเซลล์เมทริกซ์ = (2^a) × (2^a) = 4^a
- ฟังก์ชัน `recur` จะลงไปจนถึง `a == 0` และที่ระดับสุดท้าย (leaf) จะเขียนค่าลงในแต่ละเซลล์หนึ่งครั้ง
- จำนวน leaf = 4^a (เท่ากับจำนวนเซลล์) และแต่ละ leaf ทำงาน O(1)
- ดังนั้นเวลารวมเป็น Θ(4^a)

ถาเขียนเทียบกับขนาดเมทริกซ์ `n = 2^a`:
- Time = Θ(n^2)
- Space: เก็บเมทริกซ์ต้อง O(n^2) (รวมพื้นที่สำหรับ `v`) และ stack depth = O(a) = O(log n)
