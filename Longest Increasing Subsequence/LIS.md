# Longest Increasing Subsequence (LIS)

## 1. วิเคราะห์โจทย์ Longest Increasing Subsequence
กำหนดลำดับเต็มของจำนวนเต็ม `S = ⟨s₁, s₂, …, sₙ⟩`  
"subsequence" คือ ลำดับที่ได้จากการลบองค์ประกอบบางตัวออกโดยไม่เปลี่ยนลำดับเดิม
ตัวอย่าง: `⟨s₂, s₄, sₙ⟩` เป็น subsequence ของ `S` แต่ `⟨s₄, s₁, s₂⟩` ไม่ใช่


"Increasing subsequence" หมายถึง subsequence ที่สมาชิกมีค่าสุทธิเรียงเพิ่ม
ตัวอย่าง: `S = ⟨3,1,4,5,2⟩` → `⟨3,4,5⟩` เป็น increasing subsequence   
แต่ `⟨3,1,5⟩` แม้เป็น subsequence แต่ไม่เรียงเพิ่มเพราะ 1 < 3

โจทย์: หา **ความยาว** ของ increasing subsequence ที่ยาวที่สุดใน `S`

---

## 2. วิเคราะห์ที่มาสมการ Recurrence Relation
นิยาม `dp[i]` = ความยาวของ LIS ที่ลงท้ายด้วย `S[i]` (เลือก `S[i]` เป็นองค์ประกอบสุดท้าย)  

ฐาน: ทุกตำแหน่งเดี่ยวสามารถเป็น LIS ขนาด 1
```
dp[i] = 1   for i=0..n-1
```

สำหรับ `i` ตั้งแต่ 1 ถึง n-1 พิจารณาตำแหน่งก่อนหน้า `j < i`:
- หาก `S[i] > S[j]` สามารถต่อ `S[i]` เข้ากับ LIS ที่ลงท้าย `S[j]`
- จึงอัปเดต
```
dp[i] = max(dp[i], dp[j] + 1)   for all j < i with S[j] < S[i]
```

ค่าคำตอบสุดท้ายเป็น `max(dp[i])` สำหรับ `i=0..n-1`

วิธีนี้เป็น DP แบบสองชั้นที่รัน `O(n²)` อธิบายได้น้ำหนักการพิจารณาทุกคู่ลำดับ

(มีวิธีก้าวหน้าด้วย binary search ที่ `O(n log n)` แต่โค้ดตัวอย่างใช้ `O(n²)`)

## 3. อธิบายโค้ด + ยกตัวอย่าง testcase
โค้ดในไฟล์ `lis.cpp` อ่านค่า `N` และ `S` ดังนี้:

```cpp
int N;
cin >> N;
vector<int> S(N);
for (int i = 0; i < N; i++) cin >> S[i];

vector<int> dp(N, 1);
int max_length = 1;

for (int i = 1; i < N; i++) {
    for (int j = 0; j < i; j++) {
        if (S[i] > S[j]) {
            dp[i] = max(dp[i], dp[j] + 1);
        }
    }
    max_length = max(max_length, dp[i]);
}

cout << max_length << endl;
```

- `dp[i]` เริ่มที่ 1
- ลูปสองชั้นอ่านทุกคู่ `(j,i)` ก่อนหน้าที่ `j < i` 
- อัปเดต `max_length` ในขณะที่ก้าว
- พิมพ์ความยาวสูงสุด

### Testcase
```
13
7 0 10 21 1 6 22 4 3 5 9 8 71
```

วิเคราะห์: LIS ที่ยาวที่สุดอาจเป็น ⟨0,1,6,22,??,71⟩ เป็นต้น  
โปรแกรมให้ค่า **6** ซึ่งตรงกับตัวอย่าง

(ผู้เรียนสามารถทดลองหาลำดับจริงได้ เช่น 0,1,6,22,x,71 ความยาว 6)

---

## 4. Time Complexity
- ลูปสองชั้น `i` และ `j` ทำงาน `O(n²)`
- พื้นที่ `O(n)` สำหรับอาเรย์ `dp`

เวอร์ชัน `O(n log n)` ใช้เทคนิค `tails` และ binary search แต่ไม่อยู่ในโค้ดนี้

---

สรุป: LIS เป็นปัญหา DP พื้นฐานที่แสดงวิธีการนิยามสถานะย่อยและ recurrence จาก
การพิจารณาทุกคู่ก่อนหน้า โค้ด `lis.cpp` ให้คำตอบภายใน `O(n²)` เหมาะสำหรับ
การเรียนการสอนเรื่อง subsequences และ optimization แบบ DP
