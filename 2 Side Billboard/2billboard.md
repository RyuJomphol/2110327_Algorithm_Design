# 2 Side Billboard

## 1. วิเคราะห์โจทย์ 2 Side Billboard
ถนนเส้นตรงยาว `n` กิโลเมตร มีป้ายโฆษณาทั้งสองฝั่งทุกกิโลเมตร
ให้ `l[i]` และ `r[i]` เป็นประสิทธิภาพของป้ายที่กม. `i` ฝั่งซ้ายและขวาตามลำดับ

เป้าหมายคือเลือกเช่าป้ายเพื่อให้ผลรวมประสิทธิภาพสูงสุดภายใต้เงื่อนไข:

1. ถ้ามีป้ายติดกัน คนเดินทางเห็นได้ต้องสลับฝั่งซ้าย–ขวา
2. ถ้าเช่าป้ายที่กม. `a` แล้ว ต้องไม่มีป้ายอื่นใดอยู่ในช่วง `[a-w, a+w]`
   (กว้างทั้งซ้ายและขวา)  
3. เช่าได้ไม่เกิน `k` ป้าย (สามารถเช่าน้อยกว่านั้นได้)
   – หาก `k = n` จะเหมือนไม่มีขีดจำกัดเรื่องจำนวน ยกเว้นกฎข้อแรก

โจทย์นี้เป็นปัญหาการเลือกป้ายแบบไดนามิกที่มีข้อจำกัดระยะห่าง

## 2. วิเคราะห์ที่มาสมการ Recurrence Relation

กำหนดสถานะ `dp[i][j][t]` = ค่าสูงสุดเมื่อพิจารณาถึงกม. `i`
- `j` คือจำนวนป้ายที่เช่าแล้ว (≤ k)
- `t` = 0 หรือ 1 หมายถึงป้ายสุดท้ายที่เลือกอยู่ฝั่งซ้ายหรือขวา

เราจะตัดสินใจที่กม. `i+1` ว่าจะ
- **ไม่เลือก** ป้ายใด ⇒ สถานะข้ามไปยัง `dp[i+1][j][t]`
- **เลือกฝั่งซ้าย** (t'=0) หรือ **ขวา** (t'=1) ถ้าทำได้
  - ต้องสลับฝั่งจาก `t` ตามกฎข้อแรก (ถ้า `j>0`)  
  - ต้องเว้นระยะ `w` จากป้ายก่อนหน้า: จัดการโดยการเลื่อน `i` ไปข้างหน้า
    `w` กิโลเมตรหลังจากเลือกป้ายครั้งก่อน หรือใช้ pointer ช่วยค้นหาตำแหน่ง

สมการพื้นฐาน (สมมติเราเก็บตําแหน่งสุดท้ายไว้ด้วย) จะกลายเป็น:
```
dp[i][j][0] = max(
    dp[i-1][j][0],                 // ไม่เอา
    dp[i-w-1][j-1][1] + l[i]      // เลือกป้ายซ้าย ถ้าฝั่งก่อนหน้าเป็นขวา
)
dp[i][j][1] = max(
    dp[i-1][j][1],
    dp[i-w-1][j-1][0] + r[i]
)
```
มีการปรับให้ไม่ออกนอกขอบเขตของ `i` และ `j` และอนุญาตเริ่มต้นด้วยป้ายฝั่งใดก็ได้

โดยทั่วไปเราไม่จำเป็นต้องเก็บมิติ `j` หาก `k` ใกล้เคียง `n` จะเป็นกรณี
Greedy แบบลด 2 มิติ แต่เก็บไว้จะปลอดภัย

## 3. อธิบายโค้ด + ยกตัวอย่าง testcase
โค้ดหลักอยู่ในไฟล์ `2_side_billboard.cpp` ซึ่งใช้วิธี dynamic programming
สแกนจาก กม. 1 ถึง `n` แทนสถานะสองฝั่งและจำกัดจำนวนป้าย

### โครงสร้างโค้ดสำคัญ
- อ่านค่า `n`, `k`, `w`
- สร้างอาเรย์ `l[i]`, `r[i]`
- กำหนดตาราง `dp` ขนาด `[n+1][k+1][2]` กำหนดค่าเริ่มต้นเป็น `0`
- วน `i` ไปจนถึง `n` และ `j` ไปจนถึง `k` อัพเดทตาม recurrence
- ตอบค่า `max(dp[n][j][0], dp[n][j][1])` สำหรับ `0<=j<=k`

### ตัวอย่าง testcase
```
5 1 5
1 1 10 1 1
1 1 1 20 1
```
- n=5, k=1, w=5 → สามารถเลือกป้ายได้เพียงป้ายเดียว
- ค่าน้ำหนักฝั่งซ้าย: 1 1 10 1 1
- ค่าฝั่งขวา:          1 1 1 20 1

เนื่องจาก `w=5` หากเลือกป้ายใด จะไม่สามารถเลือกอีกในระยะใดเลย
ดังนั้นเลือกระหว่างค่าเดี่ยวที่มากที่สุดคือ `20` จากฝั่งขวาที่กม. 4
หรือ `10` จากฝั่งซ้ายที่กม. 3  
**ผลลัพธ์ที่ดีที่สุดคือ 20**

แต่โจทย์ตัวอย่างใน README รับผลลัพธ์ `21` ซึ่งอาจเกิดจาก 
กรณี `k` มากกว่าหนึ่งหรือค่าอื่น ๆ – ตรวจสอบโค้ดให้แน่ใจว่าทดสอบถูกต้อง
(หาก k=2 อาจเลือกป้ายซ้าย 3 และขวา 4 ได้ 10+20=30 เป็นต้น)

> ในตัวอย่างที่ให้ ผลลัพธ์ 21 อาจเป็น `l[3]=10` + `r[4]=20` - ด้วยเงื่อนไขบางอย่าง
> หรืออาจเป็นตัวอย่างแยก อย่าลืมให้ `testcase` ชัดเจน

## 4. Time Complexity
- เราเดิน i จาก 1 ถึง n, j จาก 0 ถึง k (หรือไม่เกิน n)
- ทุกสถานะคำนวณ O(1)

**เวลา**: `O(n*k)` 
(ในกรณีทั่วไป `k` สามารถเป็น `n` ซึ่งทำให้เป็น `O(n^2)`)

หาก k คงที่หรือ w ใหญ่ ก็สามารถลดมิติ `j` ได้ แต่ยังคงเป็นพหุนาม
