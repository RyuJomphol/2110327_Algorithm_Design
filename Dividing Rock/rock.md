# Dividing Rock

## 1. วิเคราะห์โจทย์ Dividing rock
มีหิน `n` ก้อนที่มีหมายเลขตั้งแต่ 1 ถึง `n` ต้องแบ่งออกเป็น `k` กอง
โดยกองแต่ละกองต้องมีหินอย่างน้อย 1 ก้อน  
การแบ่งที่ต่างกันคือชุดของกอง (unordered) แตกต่างกัน
หมายความว่า:
- กองไม่มีป้ายลำดับ (k กองแล้วย้ายตำแหน่งกันไม่ถือว่าใหม่)
- แต่ภายในแต่ละกองหินมีป้ายกำกับจึงถือว่าแตกต่างกัน  

ตัวอย่าง: `n=3, k=2`
- ชุดกอง `{1,2}` และ `{3}`  
- `{1,3}` และ `{2}`  
- `{2,3}` และ `{1}`  
รวม 3 วิธี (การสลับตำแหน่งกองไม่เพิ่มวิธี)

โจทย์คือหาจำนวนวิธีทั้งหมดในการแบ่งเช่นนี้
(ซึ่งเท่ากับค่าของ "Stirling number of the second kind")

## 2. วิเคราะห์ที่มาสมการ Recurrence Relation
ให้ `dp[i][j]` = จำนวนวิธีแบ่งหิน `i` ก้อนเป็น `j` กอง  
ฐาน:
```
dp[0][0] = 1        // ไม่มีหินกับไม่มีคองถือว่ามีหนึ่งวิธี
dp[i][0] = 0 for i>0
dp[0][j] = 0 for j>0
```
เมื่อเพิ่มหินหมายเลข `i` เข้ามา สามารถ
1. นำหินนี้ไปต่อกองเดิมใดกองหนึ่งจาก `j` กอง  
   → มี `j * dp[i-1][j]` วิธี  
2. ตั้งเป็นกองใหม่หนึ่งกอง (เพิ่มจำนวนกอง)  
   → `dp[i-1][j-1]` วิธี

จึงได้ recurrence:
```
dp[i][j] = j * dp[i-1][j] + dp[i-1][j-1]
```
ค่าดังกล่าวตรงกับสูตรของ Stirling number S(i,j)

ในโค้ดเราอาจจะใช้การคูณ modulo (เช่น 1997 ตามตัวอย่าง)
เพื่อหลีกเลี่ยง overflow

## 3. อธิบายโค้ด + ยกตัวอย่าง testcase
โค้ดใน `dividing_rock.cpp` ใช้ DP 2 มิติและลูปซ้อน `i` จาก 1 ถึง `n`,
`j` จาก 1 ถึง `k`  
ค่าพารามิเตอร์ `MOD` ถูกตั้งเป็น `1997` (โจทย์อาจกำหนด)

### ขั้นตอนโค้ดสำคัญ
1. อ่าน `n`, `k`  
2. เช็คเงื่อนไขถ้า `k > n` หรือ `k == 0` ปริ้น `0` (เป็นไปไม่ได้)  
3. สร้างอาเรย์ `dp[n+1][k+1]` เริ่มค่าทั้งหมดเป็น `0`  
4. วน `i` และ `j` เพื่อเติมตาม recurrence กับกรณีพิเศษ `j==1` หรือ `i==j`
5. แสดง `dp[n][k]`  

### Testcase
```
7 3
```
- แบ่งหิน 7 ก้อนเป็น 3 กอง  
- ค่าที่ได้คือ `301` (ตรวจสอบได้จากสูตรหรือโค้ด)

> ผลลัพธ์: **301**

## 4. Time Complexity
- ลูป `i` ถึง `n` และ `j` ถึง `k`  
- แต่ละค่าคำนวณ `O(1)`  

**เวลา**: `O(n * k)`  
และ **พื้นที่** `O(n * k)` ซึ่งสามารถปรับลดได้เป็น `O(k)`
ด้วยการใช้ rolling array หากต้องการ
