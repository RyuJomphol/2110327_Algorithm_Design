# 📏 Distance One (ระยะห่างของเลข 1)

## 1. วิเคราะห์โจทย์ Distance One
เราต้องการหาจำนวนแบบหรือจำนวนวิธีในการสร้าง **Bit String** (สตริงที่ประกอบด้วยเลข `0` และ `1` เท่านั้น) ที่มีความยาวทั้งหมด $n$ ตัวอักษร โดยมีเงื่อนไขสำคัญคือ **หากมีเลข `1` อยู่ในสตริง เลข `1` แต่ละตัวจะต้องอยู่ห่างกันอย่างน้อย $k$ ตำแหน่งเสมอ** 
กล่าวคือ หากมีเลข 1 อยู่ที่ตำแหน่ง $a$ และตำแหน่ง $b$ แล้ว $|a - b| \ge k$ เสมอ

นอกจากนี้ ผลลัพธ์จากการนับรวมถึงจำนวนแบบอาจมีค่าที่ใหญ่มาก โจทย์จึงมีข้อกำหนดให้คำนวณหาผลลัพธ์อยู่ภายใต้มอดุโล `100,000,007` (100000007) เพื่อป้องกันปัญหาตัวเลขล้น (Integer Overflow)

## 2. วิเคราะห์ที่มา Recurrence Relation (ความสัมพันธ์เวียนเกิด)
การแก้ปัญหานี้สามารถใช้หลักการ **Dynamic Programming** โดยพิจารณาตัวอักษรตัวล่าสุดที่ตำแหน่ง $i$ (เมื่อสตริงยาว $i$) ซึ่งสามารถเป็นไปได้ 2 กรณี:

**กรณีที่ 1: ให้ตำแหน่งที่ $i$ ลงท้ายด้วย `0`**
หากตำแหน่งปัจจุบันเป็น `0` จะไม่กระทบกับเงื่อนไขระยะห่างของเลข `1` ตัวอื่นๆในอดีตเลย ดังนั้นจำนวนรูปแบบวิธีจะขึ้นอยู่กับโครงสร้างของสตริงความยาว $i-1$ ที่ถูกต้องทั้งหมด
* จำนวนวิธี = `dp[i - 1]`

**กรณีที่ 2: ให้ตำแหน่งที่ $i$ ลงท้ายด้วย `1`**
หากเราวาง `1` ที่ตำแหน่งนี้ เงื่อนไขคือ $k-1$ ตำแหน่งก่อนหน้าจะต้องห้ามโผล่เลข `1` เลย (หรือก็คือต้องเป็น `0` รวดเท่านั้น) เพื่อเว้นระยะห่างให้ครบ $k$ 
* **ถ้าระยะ $i \ge k$** เราจะต้องถอยกลับไปมองสตริงความยาว $i - k$ ซึ่งเป็นขอบเขตตำแหน่งก่อนหน้าที่จะเริ่มบังคับกรอกเลข `0` 
  * จำนวนวิธี = `dp[i - k]`
* **ถ้าระยะ $i < k$** แปลว่าความยาวยังไม่พอที่จะวางเลข `1` ได้เกิน 1 ตัว (ทั้งสตริงมีเลข `1` ได้แค่จุดเดียวคือจุดท้ายสุดนี้) 
  * จำนวนวิธี = `1` (เป็นแบบที่ตำแหน่งก่อนหน้าทั้งหมดตั้งแต่ตัวแรกต้องเป็น `0` เท่านั้น)

**สรุปสมการ Recurrence Relation:**
* $dp[i] = dp[i - 1] + 1$ (สำหรับ $i < k$)
* $dp[i] = dp[i - 1] + dp[i - k]$ (สำหรับ $i \ge k$)

*(โดยกำหนด Base case คือ $dp[0] = 1$ เสมือนว่าสตริงว่างนับเป็น 1 ความเป็นไปได้)*

## 3. อธิบายโค้ด
โค้ดภาษา C++ ใช้แนวทางการสร้างตารางเก็บคำตอบ (Tabulation แบบ Bottom-up) มาช่วยขจัดปัญหา Overlapping Subproblem:

1. **การรับค่าเริ่มต้น:** `cin >> n >> k;` รับความยาวสตริงและระยะห่างขั้นต่ำ
2. **ตัวแปร Modulo:** กำหนด `mod_num = 100000007` เพื่อดูแลเรื่อง Integer Overflow
3. **การสร้าง DP Table:** ประกาศ `vector<int> dp(n + 1)` เพื่อสะสมจำนวนรูปแบบของสตริงที่สร้างได้ตั้งแต่ความยาว $0$ จนถึง $n$
4. **กำหนดค่าฐาน:** ให้ `dp[0] = 1;` 
5. **การทำงานของลูป `for`:**
   * วนลูปตั้งแต่ความยาว $i = 1$ ถึง $n$
   * `dp[i] = dp[i - 1];` (ทดตั้งต้นจำลองไว้ก่อนว่าลงท้ายด้วย 0)
   * เข้าสู่เงื่อนไข `if (i < k)`: หากสเกลความยาวยังไม่ถึง $k$ ให้บวกเพิ่มอีก `1` (กรณีลงท้ายด้วย 1 แล้วที่เหลือห้ามมี 1 เลย) พร้อมทำการ Modulo ด้วย `mod_num`
   * เข้าสู่เงื่อนไข `else`: หากความยาวผ่านเกณฑ์ $k$ แล้ว จึงนำกรณีที่ลงท้ายด้วย 1 มาคิด โดยต้องบวกเพิ่มด้วยจำนวนวิธีในช่วงความยาว $i - k$ หรือนั่นคือการบวก `dp[i - k]` แล้วทำการ Modulo 
6. **แสดงผลลัพธ์:** เมื่อลูปทำงานแล้วเสร็จ พิมพ์ค่าคำตอบสุดท้ายคือ `dp[n]` ซึ่งก็คือจำนวนผลลัพธ์ของ Bit String ความยาว $n$ ออกมา

## 4. Time Complexity
**ความซับซ้อนด้านเวลา (Time Complexity):** **$O(n)$**
เหตุผล: การทำงานของโปรแกรมมีลูปเพียงแค่ชั้นเดียว (วนตัวแปร `i` ตั้งแต่ $1$ ถึง $n$) และในแต่ละรอบเป็นการคำนวณดึงค่าจากการอ้างอิง Array ธรรมดา การบวกลบ และการหาค่า Modulo (ทั้งหมดนี้ใช้เวลาเพียง $O(1)$) ทำให้มีระยะเวลาของการทำงานแปรผันผูกติดกับขนาดความยาว $n$ แบบเชิงเส้น 

*(เพิ่มเติม)*
**ความซับซ้อนด้านพื้นที่ (Space Complexity):** **$O(n)$**
เหตุผล: โค้ดมีการใช้หน่วยความจำในการสร้างโครงสร้างข้อมูลอาเรย์ `vector<int> dp(n + 1)` ไว้เพื่อบันทึกและจดจำค่าคำตอบเก่าทุกระดับ หากต้องการประหยัดพื้นที่สามารถปรับโค้ดให้จำเฉพาะ $k$ ตำแหน่งล่าสุดได้ (เช่น ทำงานอยู่บน Circular Array ด้วยเป้าหมาย Space Complexity เป็น **$O(k)$**)
