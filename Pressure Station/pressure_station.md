# Pressure Station

## 1. วิเคราะห์โจทย์ Pressure station
มีอุโมงค์แบ่งเป็น `N` ช่วงความยาว 1 เมตรแต่ละช่วงมีเลข 1..N
ต้องติดตั้งสถานีควบคุมความดันซึ่งแต่ละแห่งครอบคลุมช่วง `K` เมตรทั้งด้านซ้ายและขวา
(สถานีที่ตำแหน่ง `S` สามารถควบคุมช่วง `[S-K, S+K]`)

ทุกช่วงสภาพอากาศต้องได้รับการควบคุม "เต็ม" (ครอบคลุมทุก segment 1..N)
การติดตั้งสถานีที่ตำแหน่ง `i` มีค่าใช้จ่าย `p[i]` ซึ่งไม่เท่ากัน
ต้องหาค่าใช้จ่ายขั้นต่ำเพื่อวางสถานีจำนวนไม่จำกัดให้ครอบคลุมทุก segment

---

## 2. วิเคราะห์ที่มาสมการ Recurrence Relation
นิยาม DP แบบ "พื้นที่ครอบคลุมสุดท้าย"  
ให้ `dp[i]` = ค่าใช้จ่ายขั้นต่ำเพื่อให้ช่วง `1..i` ได้รับการควบคุม

เมื่อพิจารณาการวางสถานีตัวสุดท้ายที่ช่วยควบคุมตำแหน่ง `i` จะตั้งอยู่ที่
ตำแหน่ง `j` ที่สามารถครอบคลุม `i` ได้ คือ `j + K >= i` 
และสถานี `j` จะครอบคลุมถึง `j-K` ด้านซ้าย
ดังนั้น `j` ต้องถูกวางโดยให้จุดก่อนหน้า (ไม่รวม j เอง)
ถูกควบคุมจนถึงอย่างน้อย `j-K-1` (หรือ `0` ถ้า j-K≤0)

เราจึงได้เงิน recurrence:
```
dp[i] = min_{j: j+K>=i} ( dp[max(0, j-K-1)] + p[j] )
```
โดย `j` วิ่งจาก `i-K` ถึง `i+K` (แต่ j ต้องอยู่ใน `[1,N]`)
และ `max(0, j-K-1)` คือพิกัดที่ต้องครอบคลุมก่อนวาง j
ค่าดังกล่าวสามารถคำนวณด้วยโครงสร้างข้อมูลสไตล์ "queue" เพื่อให้เร็ว

โค้ดใน workspace ใช้ deque เก็บดัชนี `dq` ที่มี `dp[...]` น้อยที่สุดในการคำนวณ
ปรับตามพิกัด `i-2K-1` เพื่อรักษา sliding window ความยาว `2K+1`

## 3. อธิบายโค้ด + ยกตัวอย่าง testcase
โค้ดใน `pressure_stattion.cpp` มีแนวทางดังนี้:
1. อ่าน `N`, `K` และอาเรย์ `p[1..N]`
2. เตรียมอาเรย์ `dp[1..N]` กำหนดค่าเริ่มต้นเป็น INF
3. สร้าง `deque<int> dq` เพื่อเก็บตำแหน่ง j ที่เป็นไปได้

ลูป `i = 1..N`:
- ถ้า `i <= K+1` สามารถวางสถานีที่ `i` โดยไม่ต้องพึ่งพาก่อนหน้า → `dp[i] = p[i]`
- มิฉะนั้น:
  - ลบตำแหน่งออกจากข้างหน้า dq ถ้ามันออกนอกช่วง `i - 2K - 1`
  - หาก dq ไม่ว่าง ให้ `dp[i] = dp[dq.front()] + p[i]`
  - (หมายเหตุ: dq.front() เป็นตำแหน่ง j ที่ให้ dp[j] ต่ำสุดภายใน window)
- หลังคำนวณ dp[i] แล้วลบตำแหน่งที่มีค่า dp[.] ≥ dp[i] จากด้านหลัง dq
  แล้ว push_back(i)

สุดท้าย ไขค่าคำตอบเป็นค่าต่ำสุดของ `dp[i]` สำหรับ `i` ในช่วง `[max(1, N-K), N]`
เพราะปลายสุดของ tunnel ต้องมีสถานีครอบคลุม (ตำแหน่ง j ที่เขียนไว้สามารถครอบคลุม N)

### ตัวอย่าง testcase
```
5 1
99 1 99 1 99
```
- K=1 หมายถึงแต่ละสถานีครอบคลุมตัวมันและข้างเคียง 1 ตำแหน่ง
- ค่า p: 99,1,99,1,99

วิธี: วางสถานีที่ตำแหน่ง 2 และ 4 → ครอบคลุมทุก segment 1..5
ค่าใช้จ่าย = 1 + 1 = 2  
เป็นค่าใช้จ่ายต่ำสุด (วางที่อื่นจะมี 99)

คาด output: **2**

## 4. Time Complexity
- ลูปลูป `i = 1..N` และทุกตำแหน่งเข้า-ออก deque อย่างน้อยหนึ่งครั้ง
- การอัพเดตและตรวจสอบองค์ประกอบ dq เป็น O(1) ต่อการดำเนินการ

ดังนั้นเวลาโดยรวม **O(N)**  
และใช้พื้นที่ **O(N)** สำหรับอาเรย์ `dp` และ `p` (deque ใช้ O(N) กรณีแย่)

### สรุป
ปัญหา Pressure Station เป็นตัวอย่างของ DP เต็มรูปแบบที่ใช้ `deque` (sliding window optimization)
เพื่อหาตำแหน่งวางสถานีสุดท้ายที่เหมาะสมในช่วง `2K+1` ตำแหน่งก่อนหน้า
โค้ดมีประสิทธิภาพเชิงเส้นและใช้งานได้ง่ายสำหรับการสอน
