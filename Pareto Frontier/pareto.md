# Pareto Frontier

## 1. วิเคราะห์โจทย์ — วิธีที่ใช้

ปัญหา Pareto Frontier (หรือ Skyline Problem): หาจำนวนจุด "ไม่ถูกครอบงำ" จากชุดของจุดในระนาบ 2D

**นิยาม:** จุด (x₁, y₁) ถูกครอบงำโดยจุด (x₂, y₂) ถ้า x₁ ≤ x₂ และ y₁ ≤ y₂ และอย่างน้อยหนึ่งอสมการเป็นสมการ
จุดที่ไม่ถูกครอบงำเรียกว่า **Pareto frontier** (หรือ Pareto optimal points)

**วิธีแก้:** Greedy ร่วมกับการเรียงลำดับ
1. เรียงจุดตามค่า x จากมากไปน้อย (descending)
2. สแกนจากจุดที่มี x สูงสุด: ถ้า y มากกว่าค่า y สูงสุดที่เหมิน ก่อนหน้า แสดงว่ามันเป็น Pareto frontier
3. นับจำนวนจุดดังกล่าว

เหตุผลการทำงาน: เมื่อ x เรียงจากมากไปน้อย สำหรับแต่ละจุดใน Pareto frontier ต้องมี y ที่มากกว่าค่า y สูงสุดปัจจุบัน ถ้าไม่ ก็อยู่ภายใต้ Pareto frontier ที่เพิ่งพบแล้ว

## 2. วิเคราะห์โค้ด

```cpp
int N;
cin >> N;
vector<pair<int,int>> ordered_pair(N);
```
อ่าน N คู่อันดับ (x, y) เก็บใน vector of pairs

```cpp
sort(ordered_pair.begin(), ordered_pair.end(), [](auto &a, auto &b) {
    return a.first > b.first;
});
```
**การเรียงลำดับ:** Lambda function ที่เรียง pairs โดย `a.first > b.first` (ลำดับจากมากไปน้อยตามค่า x)

```cpp
int maxY = -1;
int count = 0;

for (auto order : ordered_pair) {
    if (order.second > maxY) {
        count++;
        maxY = order.second;
    }
}
```
**ลูปสแกน:**
- เก็บค่า `maxY` ซึ่งเป็นค่า y สูงสุดที่พบจนถึงตอนนี้
- สำหรับแต่ละจุด: ถ้า y ปัจจุบัน > maxY แสดงว่ามันเป็น Pareto frontier
- นับและอัปเดต maxY

ข้อสังเกต: เริ่มต้น `maxY = -1` เพื่อให้จุดแรกของเมทริกซ์เรียงแล้วมีแน่ใจว่ามี y > -1 (ถ้า y มีค่า ≥ 0)

## 3. ตัวอย่าง Test Case (ตามที่ให้)

Input:
```
4
 20 40
 21 21
 40 20
 41 41
```

คู่อันดับ:
- P₁ = (20, 40)
- P₂ = (21, 21)
- P₃ = (40, 20)
- P₄ = (41, 41)

Expected Output:
```
1
```

**ขั้นตอนการแก้:**

1. **เรียงลำดับตามค่า x จากมากไปน้อย:**
   ```
   (41, 41) → (40, 20) → (21, 21) → (20, 40)
   ```

2. **สแกนหา Pareto Frontier:**

   | i | (x, y) | maxY ก่อน | y > maxY? | maxY หลัง | count |
   |---|--------|-----------|-----------|-----------|-------|
   | 0 | (41, 41) | -1 | 41 > -1? ✓ | 41 | 1 |
   | 1 | (40, 20) | 41 | 20 > 41? ✗ | 41 | 1 |
   | 2 | (21, 21) | 41 | 21 > 41? ✗ | 41 | 1 |
   | 3 | (20, 40) | 41 | 40 > 41? ✗ | 41 | 1 |

   **ผลลัพธ์: count = 1** (ประกอบด้วยจุดเดียว: (41, 41))

## 4. วิเคราะห์ด้วย ASCII Visualization

**ระนาบ 2D ของคู่อัน:**

```
y
|
41 ├─────────────────●────────────→ (41,41)
   │
   │
40 ├──────────────────────────────●─ (20,40)
   │
   │
21 ├────────────────●────────────── (21,21)
   │
   │
20 ├──────────────●────────────────── (40,20)
   │
 -1├────────────────────────────────
   └────────────────────────────────→ x
    0   20   21   40   41
```

**ทำเครื่องหมายจุด:**
- (41, 41) = ●  **← Pareto Frontier** (มี y สูงสุดเมื่อ x สูงสุด)
- (40, 20) = ◌  ถูกครอบงำโดย (41, 41) (x และ y ต่ำกว่า)
- (21, 21) = ◌  ถูกครอบงำโดย (41, 41)
- (20, 40) = ◌  ถูกครอบงำโดย (41, 41) ในแกน x (แม้ว่า y อาจเท่ากัน)

**Explanation of Domination:**
- (41, 41) ≥ (40, 20): 41 ≥ 40 ✓ และ 41 ≥ 20 ✓ → (40, 20) ถูกครอบงำ
- (41, 41) ≥ (21, 21): 41 ≥ 21 ✓ และ 41 ≥ 21 ✓ → (21, 21) ถูกครอบงำ
- (41, 41) ≥ (20, 40): 41 ≥ 20 ✓ แต่ 41 ≥ 40 ✓ → (20, 40) ถูกครอบงำ

→ ดังนั้น Pareto frontier มีเพียงจุดเดียว: **(41, 41)**

## 4. Complexity (Big O / Big Theta)

- **ขั้นอ่านข้อมูล:** O(N)
- **การเรียงลำดับ:** O(N log N) (merge sort / quick sort ที่ใช้ใน `std::sort`)
- **ขั้นสแกน:** O(N) (สแกนแต่ละจุดเพียงครั้งเดียว)
- **Overhead (comparisons) ในสแกน:** O(1) ต่อจุด

**Time Complexity:**
$$T(N) = O(N) + O(N \log N) + O(N) = O(N \log N)$$

**Space Complexity:**
- vector ที่เก็บ pairs: O(N)
- ตัวแปร helpers (maxY, count): O(1)
$$S(N) = O(N)$$

**Big Theta:**
$$\Theta(N \log N)$$ สำหรับ Time (ครอบงำโดยการเรียงลำดับ)
$$\Theta(N)$$ สำหรับ Space
