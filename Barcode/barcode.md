# Barcode

## 1. วิเคราะห์โจทย์ Barcode

กำหนดบาร์โค้ดเป็นสตริงของ ‘0’ (สีดำ) และ ‘1’ (สีขาว) ยาว `N` ตัวอักษร
มีเงื่อนไขที่ต้องปฏิบัติตาม:

1. ความยาวต้องเป็น `N`
2. ไม่อนุญาตให้มีสีเดียวกันต่อเนื่องเกิน `M` ครั้ง
3. ต้องมีจำนวนครั้งที่สีเปลี่ยนระหว่างตำแหน่งติดกันเท่ากับ `K`
   (color changing นับเมื่อสองบิตที่อยู่ติดกันต่างกัน)
4. บิตตัวแรกต้องเป็น `0` (สีดำ)

โจทย์: หาจำนวนบาร์โค้ดที่เป็นไปได้ทั้งหมดภายใต้เงื่อนไขดังกล่าว

---

## 2. วิเคราะห์ที่มาสมการ Recurrence Relation

สมมติว่าเราแบ่งบาร์โค้ดออกเป็นช่วง (run) ของสีเดียวกัน
แต่ละช่วงยาวระหว่าง `1` ถึง `M` และสีจะสลับไปมา
เราต้องการนับลำดับ run ที่รวมความยาวเป็น `N` และมี `K`
จุดเปลี่ยนสี (จำนวน run – 1) เท่ากับ `K`  
เพราะทุก ๆ การเปลี่ยนสีสร้าง run ใหม่

นิยาม `dp[i][j]` = จำนวนลำดับของความยาวรวม `i` ที่มี `j` การเปลี่ยนสี
โดยเริ่มด้วยสีดำเสมอ  
(เราไม่จำเป็นต้องเก็บสีปัจจุบันเพราะการสลับสีเป็นสม่ำเสมอ)

- เมื่อ `j = 0` หมายถึงไม่มีการเปลี่ยนสี → ทั้งหมดเป็นบล็อกสีดำเดียว
  ดังนั้น `dp[i][0] = 1` เมื่อ `i ≤ M` และ `0` เมื่อ `i > M`
- สำหรับ `j > 0` ให้เลือกความยาวของบล็อกแรก `len` (สีดำ) ระหว่าง `1..M`  
  แล้วบันทึกว่าหลังจากนั้นเราต้องสร้างลำดับยาว `i - len` ที่มี `j-1`
  การเปลี่ยนสี (เริ่มจากสีขาว)

สูตร recurrence จะกลายเป็น:
```
dp[i][j] = Σ_{len=1..M, i-len≥1} dp[i - len][j - 1]
```
(สำหรับทุก `i=1..N`, `j=1..K`)  

คำตอบสุดท้ายคือ `dp[N][K]`  
นิยามนี้ตรงตามโค้ดที่มีอยู่: ลูปสามชั้นคำนวณค่าข้างต้น

## 3. อธิบายโค้ด + ยกตัวอย่าง testcase

โค้ดใน `barcode.cpp` ใช้ DP สองมิติ `dp[N+1][K+1]`

### โครงสร้างโค้ดหลัก
```cpp
vector<vector<long long>> dp(N + 1, vector<long long>(K + 1, 0));

// ค่าเริ่มต้น j=0
for (int i = 1; i <= N; i++) {
    if (i <= M) dp[i][0] = 1;
    else dp[i][0] = 0;
}

for (int j = 1; j <= K; j++) {
    for (int i = 1; i <= N; i++) {
        for (int len = 1; len <= M; len++) {
            if (i - len >= 1) {
                dp[i][j] += dp[i - len][j - 1];
            }
        }
    }
}

cout << dp[N][K] << endl;
```

- ขอบเขต `i-len >= 1` ป้องกันลบ
- ค่าที่ได้คือจำนวนบาร์โค้ดทั้งหมดตามเงื่อนไข

### ตัวอย่าง
```
7 9 4
```
- N=7, M=9 (ระยะจำกัดยาวกว่ายาวจริง จึงไม่มีผล)  
- K=4 การเปลี่ยนสีต้องเกิด 4 ครั้ง  
- เนื่องจาก N=7 มี run 5 (j+1) เข้ากับ K=4
  เราเพียงเลือกลำดับความยาว run ที่รวมเป็น 7 แล้วสลับสีทุกครั้ง

รันโค้ดจะได้ผลลัพธ์: **15**  
(สามารถตรวจสอบด้วยการ brute-force ย่อมได้)

## 4. Time Complexity
- `i` มี `N` ค่า, `j` มี `K` ค่า, `len` มี `M` ค่า
- การคำนวณ `dp[i][j]` แต่ละตัวใช้ `O(M)`

**เวลา**: `O(N * K * M)`  
**พื้นที่**: `O(N * K)`

ตัวแปรสามารถใช้แบบ 64‑bit เพื่อให้รองรับผลลัพธ์ใหญ่

---

บทสรุป: Barcode เป็นตัวอย่างของ DP ที่จัดการกับ
การนับสตริงภายใต้ข้อจำกัดด้านความยาว run และการเปลี่ยนสี
สมการเรียบง่ายและสามารถขยายไปใช้กับปัญหาอื่น ๆ ที่คล้ายกัน
