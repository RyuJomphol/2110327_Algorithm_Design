# 🪧 Advertising Billboard (ป้ายโฆษณา)

## 1. วิเคราะห์โจทย์ Advertising Billboard
เราต้องการเช่าป้ายโฆษณา (Billboard) ที่เรียงต่อกันอยู่ริมสี่แยกหรือถนนสายยาวเส้นหนึ่งตั้งแต่ป้ายที่ 1 ไปจนถึง N โดยแต่ละป้ายจะมีจำนวนลูกค้าที่เห็นไม่เท่ากันคือ `c[i]` คน เราต้องการทำให้โฆษณาของเราเข้าถึงคนจำนวนมากที่สุดเท่าที่จะทำได้ 
แต่มีเงื่อนไขสำคัญคือ **"ห้ามเช่าป้ายโฆษณา 2 ป้ายที่อยู่ติดกันเด็ดขาด"** (เพื่อไม่ให้ลูกค้าเบื่อ)
ปัญหานี้สามารถจัดอยู่ในกลุ่มหาค่า Maximum Independent Set ในอาร์เรย์ 1 มิติ (หรือหลายคนรู้จักในชื่อปัญหา House Robber) โดยต้องหาว่า เราจะเลือกกลุ่มของช่องอย่างไรให้ผลรวมค่าของมันเยอะที่สุดภายใต้ข้อกำหนดที่ว่า ห้ามเลือก 2 ช่องที่ index ติดกัน

## 2. วิเคราะห์ที่มาสมการ Recurrence Relation
ในการแก้ปัญหาด้วย Dynamic Programming (DP) เราจะเริ่มพิจารณาทีละป้ายจากซ้ายไปขวา
สมมติให้ `dp[i]` เป็นค่าจำนวนคนที่เข้าถึงโฆษณารวมมากที่สุด เมื่อพิจารณาป้ายที่ 1 ถึงป้ายที่ i 

ในการตัดสินใจที่ป้ายหมายเลข i เรามีทางเลือกเพียง 2 ทาง:
1. **ไม่เช่าป้ายที่ i (Skip current):** หากเราไม่เอาป้ายนี้ จำนวนคนที่ได้ก็จะต้องพึ่งพาการซื้อป้ายที่เหลือถึงแค่ป้ายที่ i - 1 ดังนั้นจะได้ยอดเท่ากับยอดที่ดีที่สุดก่อนหน้า คือ `dp[i - 1]`
2. **เช่าป้ายที่ i (Take current):** หากเรายืนยันจะเอาป้ายนี้ กฎข้อบังคับบอกว่าเราจะ**ห้ามเช่าป้ายที่ i - 1** เด็ดขาด ฉะนั้นเราจึงต้องย้อนกลับไปใช้ยอดสะสมรวมของโฆษณาที่อยู่ตำแหน่งก่อนหน้านั้นไปอีกขั้นหนึ่ง นั่นก็คือ `dp[i - 2]` แล้วนำมาบวกด้วยจำนวนคนเห็นของป้าย i นี้นั่นคือ `ads[i]` ซึ่งยอดรวมจะได้เป็น `dp[i - 2] + ads[i]`

เพื่อให้ได้ยอดคนเห็นมากที่สุด เราจะนำทั้ง 2 กรณีด้านบนเทียบกันและเลือกเฉพาะค่า Maximum:
**สมการ Recurrence Relation:**
`dp[i] = max( dp[i - 1], dp[i - 2] + ads[i] )`

**Base Cases (กรณีฐานเริ่มต้น):**
* `dp[0] = 0` (ถ้าไม่มีป้ายเลย ก็จะมีคนเห็นเป็นศูนย์)
* `dp[1] = ads[1]` (ถ้าพิจารณาแค่ป้ายที่ 1 ก็ต้องเลือกเช่าอันนี้เพื่อเอาค่าสูงสุดก่อน)

## 3. อธิบายโค้ดและยกตัวอย่าง Testcase
**การทำงานของโค้ด:**
1. โปรแกรมรับค่า $N$ ซึ่งเป็นจำนวนป้ายโฆษณาทั้งหมด
2. ถ้ารับแล้วพบว่า $N=0$ หรือ $N=1$ ถือเป็นกรณีเล็กๆ ก็ให้ตีค่าตอบเลยแล้วเคลียร์จบการทำงาน
3. ประกาศตัวแปรจดบัญชี `vector<int> dp(N + 1)` 
4. กำหนด Base cases: ให้ `dp[0] = 0` และ `dp[1] = ads[1]`
5. เข้าสู่วงลูปเพื่อประมวลผลตั้งแต่ป้าย `i=2` จนถึง `N`:
   * ให้ `skip_current = dp[i-1]` 
   * ให้ `take_current = dp[i-2] + ads[i]`
   * เก็บค่าสุดท้ายที่ชนะการเปรียบเทียบจาก `max` ลงในตาราง `dp[i]` 
6. สิ้นสุดการทำงาน ป้ายสุดท้ายของตารางบัญชี ย่อมจะเป็นคำตอบที่ดีที่สุด ให้ปริ้นค่า `dp[N]`

**ยกตัวอย่าง Test Case:**
**Input:** 
จำนวน 3 ป้าย แต่ละป้ายมีคนเห็น `3 4 2` คน (ค่า $N=3, \text{ads}=[3, 4, 2]$)
**การคาดการณ์ยอด DP:**
* `dp[0] = 0` 
* `dp[1] = ads[1] = 3` (เลือกป้ายที่ 1)
* **พิจารณาป้ายที่ 2:** เทียบ 2 กรณี 
  1. ไม่เอาป้ายที่ 2 = `dp[1]` = 3
  2. เอาป้ายที่ 2 = `dp[0] + 4` = 0 + 4 = 4
  ค่า `max(3, 4) = 4` ดังนั้น `dp[2] = 4` 
* **พิจารณาป้ายที่ 3:** เทียบ 2 กรณี
  1. ไม่เอาป้ายที่ 3 = `dp[2]` = 4
  2. เอาป้ายที่ 3 = `dp[1] + 2` = 3 + 2 = 5 *(หมายความว่าเราเช่าป้ายที่ 1 แล้วข้าม 2 มาเช่า 3)*
  ค่า `max(4, 5) = 5` ดังนั้น `dp[3] = 5`

ผลลัพธ์สุดท้ายคือ `dp[3] = 5` ซึ่งตรงกับโจทย์ที่ตัวอย่างกำหนดยอด Output ไว้เป็น 5

## 4. Time Complexity
**ความซับซ้อนด้านเวลา (Time Complexity):** **$O(N)$**
เหตุผล: เพราะโปรแกรมเดินหน้าสร้างบัญชียืดขยายจาก `i = 2` ไปจบที่ความกว้างป้าย `N` ในการเรียกใช้งานและเปรียบเทียบคำนวณ (`max`) ใช้เวลาต่อรอบเป็นค่าคงที่สเต็ปนึง ($O(1)$) ระยะเวลาของการวนลูปทั้งหมดจึงจบเป็นเวลาแปรผันผกผันกับจำนวนของ $N$ โดยไม่ย้อนกลับ ซึ่งให้ผลการวิเคราะห์ระดับเส้นตรงที่ดีเยี่ยม

*(เพิ่มเติม)*
**ความซับซ้อนด้านพื้นที่ (Space Complexity):** **$O(N)$**
เหตุผล: การแก้โจทย์ในวิธีดังกล่าว เราประกาศสร้างเวกเตอร์ 2 ตัว ได้แก่ `ads(N+1)` เพื่อเก็บยอดหน้าป้ายและ `dp(N+1)` เพื่อเก็บเป้าคะแนน รวมกันใช้ความจุคงที่ประมาณ $O(N)$ (สามารถลดพื้นที่เหลือได้ $O(1)$ หากยอมลดตัวแปรก่อนหน้าของ `dp` ให้เหลือจำแค่ 2 ตัวล่าสุดของผลลัพธ์)
