# G A A

## 1. วิเคราะห์โจทย์
โจทย์: ให้หาอักขระตัวที่ `n` ในลำดับที่ถูกสร้างแบบ recursive โดยเริ่มจากสตริงฐาน `S_0 = "gaa"` และสำหรับแต่ละระดับ `k>0` สร้าง

S_k = S_{k-1} + M_k + S_{k-1}

โดย `M_k` เป็นบล็อกความยาว `k+3` ที่มีรูปแบบ: `'g'` ตามด้วย `(k+2)` ตัวอักษร `'a'` (ตัวแรกของบล็อกเป็น `g` ส่วนที่เหลือเป็น `a`) ดังนั้น
- S_0 = "gaa" (len=3)
- S_1 = S_0 + "gaaa" + S_0 (len = 3 + 4 + 3 = 10)
- S_2 = S_1 + "gaaaa" + S_1 (len = 10 + 5 + 10 = 25)

วิธีที่ใช้คือการติดตามตำแหน่ง `n` โดยไม่ต้องสร้างสตริงทั้งหมด: ระบุว่า `n` อยู่ในซีกซ้าย / บล็อกกลาง / ซีกขวา แล้วทำ recursion ลงไปจนถึงฐาน (divide-and-conquer on lengths).

## 2. วิเคราะห์โค้ด
ฟังก์ชันหลัก:

```cpp
char find_char(int n, int k, int current_len)
```
พารามิเตอร์
- `n`: ตำแหน่งที่ต้องการ (1-indexed)
- `k`: ระดับปัจจุบัน (จำนวนครั้งของการขยาย)
- `current_len`: ความยาวของ `S_k`

ตรรกะสำคัญ:
- ถ้า `k == 0` → อยู่ใน `S_0` ซึ่งเป็น "gaa" → ถ้า `n == 1` คืน `'g'` มิฉะนั้นคืน `'a'` (ตำแหน่ง 2 และ 3 เป็น `a`).
- คำนวณ `prev_len = (current_len - (k + 3)) / 2` เพราะ `current_len = 2*prev_len + (k+3)`.
- หาก `n <= prev_len` → อยู่ในซีกซ้าย → เรียก `find_char(n, k-1, prev_len)`.
- หาก `n <= prev_len + (k + 3)` → อยู่ในบล็อกกลาง → ถ้าเป็นตัวแรกของบล็อก (`n == prev_len + 1`) คืน `'g'` มิฉะนั้นคืน `'a'`.
- มิฉะนั้น (`n > prev_len + (k+3)`) → อยู่ในซีกขวา → เรียก `find_char(n - prev_len - (k + 3), k-1, prev_len)` (เลื่อนพิกัดเข้าไปในซีกขวา).

ใน `main()` โปรแกรมคำนวณ `k` และ `len` ให้เป็นระดับ/ความยาวที่พอรองรับ `n` โดยเริ่ม `len = 3, k = 0` แล้วทำ
```
while (len < n) { k++; len = 2*len + (k+3); }
```
จากนั้นพิมพ์ `find_char(n, k, len)`

## 3. ตัวอย่าง Test Case
Input:
```
11
```
Output:
```
g
```

อธิบายสั้น ๆ (ใช้ S_0, S_1, S_2):
- S_0 = "gaa" (len=3)
- S_1 = "gaa" + "gaaa" + "gaa" = "gaagaaagaa" (len=10)
- S_2 = S_1 + "gaaaa" + S_1 (len=25)

ตำแหน่ง `n=11` อยู่ใน S_2 ที่บล็อกกลาง เพราะ
- prev_len (สำหรับ k=2) = (25 - 5) / 2 = 10
- บล็อกกลางครอบคลุมตำแหน่ง 11..15 (prev_len+1 .. prev_len+5)
- ตำแหน่ง 11 = prev_len + 1 → ตัวแรกของบล็อกกลาง → `'g'`

ASCII / บล็อกมุมมอง (S_2):

[ LEFT (S_1, len=10) ] [ MIDDLE (len=5: 'g' 'a' 'a' 'a' 'a') ] [ RIGHT (S_1, len=10) ]
 indices: 1........10 11 12 13 14 15 16......25
                                   ^
                                   n=11 → 'g'

## 4. Complexity (Big O / Big Theta)
- เวลาต่อการค้นหา: แต่ละครั้งลดระดับ `k` ลง 1 จนถึงฐาน → O(k).
- เนื่องจากความยาวเพิ่มแบบทวีคูณ (คร่าว ๆ len ≈ 2^k), ค่า `k = Θ(log n)`.
⇒ Time = Θ(log n).

- พื้นที่ (stack recursion): O(k) = O(log n).
- ไม่ต้องเก็บสตริงทั้งชุด (space extra = O(1) นอก stack)
